(`prisma/schema.prisma` and `src/routes/*.ts`), not idealized mockups — they
should stay accurate as long as the schema/routes are re-checked when they
change.

- [Entity-Relationship Diagram](./er-diagram.md) — database schema and
  relationships
- [Use Case Diagram](./use-case-diagram.md) — actors and their capabilities
- [Data Flow Diagram](./data-flow-diagram.md) — Level 0 context diagram and
  Level 1 process breakdown
